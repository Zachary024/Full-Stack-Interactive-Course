::: note
On macOS, **Cmd** is the Command key, **Option** is the Alt key and **Ctrl** is Control. Windows and Linux mostly share shortcuts, so they share a column. Where Linux differs, it is noted. Pick five shortcuts that you do not know yet, use them for a week, and then pick five more.
:::

::: learn
Reaching for the mouse costs about two seconds each time. A developer who saves ten of those every hour saves hours every month. But do not try to memorise this page. Learn a small group at a time, and let your fingers remember them.
:::

::: cheat Useful Console tricks
cols: Type this ;; What it does ;; Example
code: 1
$0 ;; The element you selected in the Elements panel ;; $0.style.color = "red"
$$("css selector") ;; All elements that match, as an array ;; $$("a").length
copy(value) ;; Put any value on your clipboard ;; copy($$("h2").map(h => h.textContent))
