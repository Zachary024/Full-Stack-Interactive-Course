Command Line Cheat Sheet

Every command-line task a developer meets, side by side for macOS and Linux (bash, zsh) and Windows (PowerShell). Filter, copy and reuse.

Note

How to use this page. Type in the filter box to search every table at once. Press Copy next to a command to put it on your clipboard. The left command column is for macOS and Linux ( or Zsh), and the right one is for Windows . Words in angle brackets, such as <file>, are placeholders for your own values. Commands marked with a dash do not have a simple equivalent.

Tip

Stuck inside a command that will not stop? Press Ctrl+C. Not sure what a command does? Run man <command> (macOS and Linux) or Get-Help <command> (PowerShell), or add --help after the command.

Pipes, redirection and chaining

In plain English

A pipe (|) feeds the output of one command into the next, like water through connected pipes. Redirection sends output to a file instead of the screen. Together they let you build powerful tools out of small commands.

Combining commands

SyntaxWhat it doesExample
cmd1 | cmd2Send the output of cmd1 into cmd2ls | grep ".txt"
cmd > fileWrite output to a file, replacing itls > files.txt
cmd >> fileAppend output to the end of a fileecho "done" >> log.txt
cmd < fileUse a file as the input of a commandsort < names.txt
cmd 2> fileWrite only the error messages to a filenpm test 2> errors.txt
cmd > file 2>&1Write normal output and errors to the same filenpm test > all.txt 2>&1
cmd > /dev/nullThrow the output awaynpm install > /dev/null
cmd1 && cmd2Run cmd2 only if cmd1 succeededmkdir out && cd out
cmd1 || cmd2Run cmd2 only if cmd1 failedcd out || echo "no such folder"
cmd1 ; cmd2Run cmd2 after cmd1, whatever happensclear ; ls
cmd &Run a command in the backgroundnode server.js &
$(cmd)Use the output of a command inside anotherecho "Today is $(date)"
cmd | tee fileShow the output and also save it to a filenpm test | tee results.txt
cmd | xargs cmd2Turn lines of output into arguments for another commandfind . -name "*.log" | xargs rm
!!Repeat the previous commandsudo !!
$?The exit code of the last command (0 means success)ls missing ; echo $?

Permissions and ownership

Permissions (macOS and Linux)

TaskCommandMeaning
Show permissionsls -lThe first column looks like -rwxr-xr-- : type, then owner, group and others
Make a file executablechmod +x <file>Allow the file to be run as a program
Remove write access for otherschmod o-w <file>o means others, - removes, w is write
Set exact permissions (owner all, others read)chmod 744 <file>7 is rwx, 4 is r--
Typical permissions for a filechmod 644 <file>Owner can read and write, everyone else can read
Typical permissions for a folder or programchmod 755 <file>Owner can do everything, others can read and run
Keep a secret file privatechmod 600 <file>Only the owner can read and write (required for SSH keys)
Change a folder and everything in itchmod -R 755 <folder>Applies the change recursively
Change the ownersudo chown <user> <file>Gives the file to another user
Change owner and groupsudo chown <user>:<group> <file>Sets both at once
Run one command as administratorsudo <command>Runs with the power of the root user. Use with care
Show who you arewhoamiPrints your user name
Show your groupsgroupsLists the groups you belong to
Note

Each permission is a number: read is 4, write is 2 and execute is 1. Add them up for each of the three groups (owner, group, others). So 7 is 4+2+1 (everything), 6 is 4+2 (read and write), 5 is 4+1 (read and run), and 4 is read only. The look-up page has a full chmod calculator table.
