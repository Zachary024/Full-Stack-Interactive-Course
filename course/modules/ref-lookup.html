HTTP status codes

CodeNameWhen you see it
100ContinueThe server received the start of the request. Keep sending
101Switching ProtocolsThe connection is upgrading, for example to a WebSocket
200OKThe request worked
201CreatedA new thing was created, usually after POST
202AcceptedReceived, and will be processed later
204No ContentIt worked, and there is nothing to send back, often after DELETE
301Moved PermanentlyThe address has changed for good. Update your links
302FoundA temporary redirect to another address
304Not ModifiedYour cached copy is still good
307Temporary RedirectLike 302 but the method stays the same
308Permanent RedirectLike 301 but the method stays the same
400Bad RequestThe request is malformed or has invalid data
401UnauthorizedYou are not logged in, or the token is missing or invalid
403ForbiddenYou are logged in but not allowed to do this
404Not FoundNothing exists at this address
405Method Not AllowedThe address exists but not for this method
408Request TimeoutThe client took too long to send the request
409ConflictThe request clashes with the current state, such as a duplicate
410GoneIt existed once and was removed on purpose
413Payload Too LargeThe request body is bigger than the server accepts
415Unsupported Media TypeThe server does not accept this Content-Type
418I am a teapotA joke status from 1998 that still exists
422Unprocessable ContentThe data is well formed but fails validation
429Too Many RequestsYou are being rate limited. Look for a Retry-After header
500Internal Server ErrorThe server crashed or hit a bug
501Not ImplementedThe server does not support this feature
502Bad GatewayA proxy got a bad answer from the server behind it
503Service UnavailableThe server is overloaded or down for maintenance
504Gateway TimeoutA proxy waited too long for the server behind it
Tip

The first digit tells you who to blame. 2xx success. 3xx go somewhere else. 4xx the client made a mistake. 5xx the server failed.

Regular expressions

In plain English

A (regex) is a pattern that describes text. It lets you search, check and replace text by rules, for example "any email address" or "three digits followed by a dash".

Regex building blocks

PatternMatchesExample
.Any one character except a new linec.t matches cat, cot and c9t
\dA digit\d\d matches 42
\DAnything except a digit\D matches a
\wA letter, digit or underscore\w+ matches hello_1
\WAnything except those\W matches a space
\sA space, tab or new linea\sb matches "a b"
\SAnything except whitespace\S+ matches word
[abc]One of the characters a, b or cgr[ae]y matches gray and grey
[a-z]One character in the range[a-z]+ matches hello
[^abc]Any character except a, b or c[^0-9] matches a
^The start of the text^Hello matches a line that begins with Hello
$The end of the textworld$ matches a line that ends with world
\bA word boundary\bcat\b matches cat but not cattle
a|bEither a or bcat|dog matches cat or dog
(abc)A group, also remembered(ab)+ matches abab
(?:abc)A group that is not remembered(?:ab)+ matches abab
\1The text matched by group 1(\w)\1 matches the double letter in book
\.A real dot (backslash switches the meaning off)3\.14 matches 3.14

Regex quantifiers and flags

PatternMeaningExample
*Zero or moreab* matches a, ab and abbb
+One or moreab+ matches ab and abbb
?Zero or one (optional)colou?r matches color and colour
{3}Exactly 3\d{3} matches 123
{2,4}Between 2 and 4\d{2,4} matches 12, 123 and 1234
{2,}2 or more\d{2,} matches 12 and 12345
*?Zero or more, as few as possible (lazy)<.*?> matches one tag at a time
(?=abc)Followed by abc, without including it\d+(?= dollars) matches 50 in "50 dollars"
(?!abc)Not followed by abcfoo(?!bar) matches foo not followed by bar
gFlag: find every match, not just the first/cat/g
iFlag: ignore upper and lower case/cat/i matches Cat
mFlag: ^ and $ work on each line/^a/m

Regex recipes

GoalPatternWarning
A simple email check^[^\s@]+@[^\s@]+\.[^\s@]+$Only a rough check. The only real test is sending an email
A date like 2026-10-23^\d{4}-\d{2}-\d{2}$Does not check that the date exists
A UK or US style phone number^\+?[\d\s-]{7,15}$Phone formats vary by country
A hex colour^#([0-9a-fA-F]{3}|[0-9a-fA-F]{6})$Handles #fff and #ffffff
A URL starting with http or https^https?://[^\s/$.?#].[^\s]*$Prefer the URL class in your language
A strong password check^(?=.*[a-z])(?=.*[A-Z])(?=.*\d).{12,}$Length matters more than special characters
Spaces at the start or end^\s+|\s+$Replace with an empty string to trim
More than one space in a row\s{2,}Replace with a single space

SQL syntax

TaskSyntaxNotes
Read rowsSELECT name, email FROM users;Use * for all columns
Filter rowsSELECT * FROM users WHERE age >= 18;Use AND, OR and NOT to combine
SortSELECT * FROM users ORDER BY name DESC;ASC is the default
Limit the number of rowsSELECT * FROM users LIMIT 10 OFFSET 20;For paging
Match a patternSELECT * FROM users WHERE name LIKE 'A%';% means any characters
Match a listSELECT * FROM users WHERE id IN (1, 2, 3);A short way to write OR
Check for nullSELECT * FROM users WHERE phone IS NULL;Never use = NULL
Remove duplicatesSELECT DISTINCT city FROM users;One of each value
Count rowsSELECT COUNT(*) FROM users;Also SUM, AVG, MIN and MAX
Group rowsSELECT city, COUNT(*) FROM users GROUP BY city;One result per group
Filter groupsSELECT city, COUNT(*) FROM users GROUP BY city HAVING COUNT(*) > 5;HAVING works on groups, WHERE on rows
Join tablesSELECT u.name, o.total FROM users u JOIN orders o ON o.user_id = u.id;Only rows that match on both sides
Keep rows with no matchSELECT u.name FROM users u LEFT JOIN orders o ON o.user_id = u.id WHERE o.id IS NULL;Users who never ordered
Insert a rowINSERT INTO users (name, email) VALUES ('Ada', 'ada@example.com');Name the columns
Update rowsUPDATE users SET name = 'Ada L.' WHERE id = 1;Always include WHERE
Delete rowsDELETE FROM users WHERE id = 1;Always include WHERE
Create a tableCREATE TABLE users (id INTEGER PRIMARY KEY, name TEXT NOT NULL);Add UNIQUE and CHECK rules
Add a columnALTER TABLE users ADD COLUMN age INTEGER;Changes the structure
Add an indexCREATE INDEX idx_users_email ON users (email);Speeds up searches on that column
Remove a tableDROP TABLE users;Cannot be undone
Start a transactionBEGIN;Followed by COMMIT or ROLLBACK
Save a transactionCOMMIT;Makes the changes permanent
Cancel a transactionROLLBACK;Undoes the changes
Show the plan of a queryEXPLAIN SELECT * FROM users WHERE email = 'a@b.c';Shows whether an index is used
