Developer Tools Cheat Sheet

Commands for npm, Python and pip, Docker, Docker Compose, curl, SSH, databases, Vim and nano, all in one searchable page.

Note

These are the tools you will meet in nearly every project. Each table lists the commands in the order you usually need them. Replace anything in angle brackets with your own value.

package.json fields

FieldWhat it isExample
nameThe package name (lower case, no spaces)"name": "my-app"
versionThree numbers: major, minor, patch"version": "1.0.0"
scriptsNamed commands you run with npm run"scripts": { "start": "node server.js" }
dependenciesPackages needed to run the app"dependencies": { "express": "^4.19.2" }
devDependenciesPackages needed only to build and test"devDependencies": { "jest": "^29.0.0" }
mainThe file that is loaded when others import the package"main": "index.js"
typeUse "module" for import and export syntax"type": "module"
enginesThe Node versions the project supports"engines": { "node": ">=20" }

curl, SSH and databases

curl

TaskCommandNotes
Fetch a URLcurl https://example.comPrints the response body
Show headers and bodycurl -i <url>Status line, headers, then the body
Show only headerscurl -I <url>Sends a HEAD request
Show everything that happenscurl -v <url>Great for debugging
Be quiet but show errorscurl -sS <url>Hides the progress bar
Follow redirectscurl -L <url>Needed for many short links
Save to a filecurl -o file.html <url>Use -O to keep the remote name
Use another methodcurl -X DELETE <url>GET is the default
Send a headercurl -H "Authorization: Bearer <token>" <url>Repeat -H for more
Send JSONcurl -X POST -H "Content-Type: application/json" -d '{"name":"Ada"}' <url>The -d sets the body
Send a formcurl -d "name=Ada&age=30" <url>URL-encoded
Upload a filecurl -F "file=@photo.png" <url>Multipart form
Send a cookiecurl -b "session=abc" <url>Use -c to save cookies
Use basic authenticationcurl -u user:password <url>Avoid for real passwords
Limit the timecurl --max-time 10 <url>Seconds
Print only the status codecurl -s -o /dev/null -w "%{http_code}" <url>Good for scripts
Time a requestcurl -w "%{time_total}\n" -o /dev/null -s <url>Total seconds

Tip

If you open Vim by accident and cannot leave, press Esc, then type :q! and press Enter. It is the most famous trap in computing, and now you know the way out.
